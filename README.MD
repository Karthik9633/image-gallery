# Image Gallery 🎨

🔗 Live Demo: https://karthik9633.github.io/image-gallery/

A modern, responsive image gallery with a **blurred background (Blux effect)** built using **HTML, CSS, and JavaScript**.

## ✨ Features
- Fullscreen blurred background synced with the active image
- Responsive design (mobile, tablet, desktop)
- Smooth image transitions
- Previous / Next navigation buttons
- Clickable indicator dots
- Clean and modern UI

## 🛠️ Technologies Used
- HTML5
- CSS3 (Flexbox, Media Queries)
- Vanilla JavaScript

1. Clone the repository
2. Open `index.html` in your browser
3. Enjoy the gallery 🎉
